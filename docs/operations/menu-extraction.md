# Menu extraction operations

Source images are uploaded privately after resource access is checked. Menu submits short-lived signed HTTPS inputs to Core; the team Runner only downloads exact-host allowlisted remote inputs into its confined workspace.

A callback is accepted only for the matching source batch/job. The extracted JSON is schema-validated and currency is normalized to integer cents. Invalid extraction does not publish. A valid first extraction publishes once idempotently and preserves its source/correlation metadata.
